Inicio Bisección Newton-Raphson Punto Fijo

Método de punto fijo (abierto)

Función original

f(x) = -x³ + 2x² - x + 3

Paso 1. Arregle la ecuación de tal forma que f(x) = 0 y que x esté del lado izquierdo de la ecuación.

Ea ≤ 0.01%

x0 = 1

x = g(x) = f(x)

a) g1(x) = x = -x³ + 2x² + 3

b) g2(x) = x = √((x³ + x - 3) / 2)

c) g3(x) = x = (2x² - x + 3)^(1/3)

Elegimos la función más sencilla.

Paso 2. Evaluar las funciones

Evaluar con un valor inicial x0 para cada función g(x) equivalente, y utilizando el nuevo valor calculado en f(x), repetir el cálculo hasta hallar la solución o convergencia.

Es decir, si conforme n crece, xn tiende a la raíz A, (A=0) se dice que el método converge. En caso contrario, diverge.

(Observar en f(x) para cada cosa)

Después de los primeros cálculos, la solución se aleja de 0. Es decir, el método diverge.

El método de iteración abierta o punto fijo permite aproximar raíces mediante la repetición de una función despejada g(x). La convergencia depende de la función elegida y del valor inicial. En cada ejercicio se verifica el error aproximado para decidir cuándo detener el procedimiento.
