Interpolación Lineal de Lagrange

La interpolación lineal es un método que permite conocer un valor desconocido de una función utilizando dos puntos conocidos: (x0, y0) y (x1, y1).

Podemos aproximar un valor intermedio suponiendo un comportamiento entre dos puntos lineales.

Fórmula:

f(x) ≈ y0 + [(y1 - y0) / (x1 - x0)] × (x - x0)

Donde:

  • x0, x1: Valores conocidos de la variable independiente.
  • y0, y1: Valores conocidos de la función.
  • x: Valor intermedio que deseamos evaluar.

Ejemplo 1: Temperatura de un procesador

Se registran temperaturas de un procesador en distintos instantes:

Tiempo (s) Temperatura (°C)
2 40
6 64

Problema: Estimar la temperatura del procesador en el segundo 4.

  • x0 = 2, y0 = 40
  • x1 = 6, y1 = 64
  • x = 4

Sustituir y resolver:

f(4) ≈ 40 + [(64 - 40) / (6 - 2)] × (4 - 2)

f(4) ≈ 40 + (24 / 4) × 2

f(4) ≈ 40 + 12

Resultado: f(4) ≈ 52 °C

Ejercicios de Interpolación Lineal

Ejercicio 1

Un sensor electrónico registra los siguientes datos:

Tiempo (s) Temp (°C)
2.5 38.4
7.5 71.6

Determina la aproximación en t = 5.8 s y calcula la pendiente.

Solución:

  • x0 = 2.5, y0 = 38.4
  • x1 = 7.5, y1 = 71.6
  • Pendiente (m): m = (71.6 - 38.4) / (7.5 - 2.5) = 33.2 / 5 = 6.64 °C/s
  • Aproximación: f(5.8) ≈ 38.4 + 6.64 × (5.8 - 2.5) = 38.4 + 6.64 × 3.3 = 38.4 + 21.912 = 60.312 °C

Ejercicio 2

Para f(x) = ln(x), utiliza los puntos x0 = 2 y x1 = 3 para aproximar ln(2.7) y calcular eabs y erel.

Solución:

  • x0 = 2 ⇒ y0 = ln(2) ≈ 0.693147
  • x1 = 3 ⇒ y1 = ln(3) ≈ 1.098612
  • Aproximación: f(2.7) ≈ 0.693147 + [(1.098612 - 0.693147) / (3 - 2)] × (2.7 - 2) = 0.693147 + 0.405465 × 0.7 ≈ 0.976973
  • Valor real: ln(2.7) ≈ 0.993252
  • Error absoluto: eabs = |0.993252 - 0.976973| = 0.016279
  • Error relativo: erel = 0.016279 / 0.993252 ≈ 0.01639 (1.64%)

Ejercicio 3

Datos de ejecución de un algoritmo:

Tamaño de entrada (n) Tiempo (ms)
100 8.5
250 29.8
  • Estima el tiempo de ejecución cuando n = 180.
  • Después determina el tamaño de entrada correspondiente estimado de 20 ms.

Solución:

  • Para n = 180: T(180) ≈ 8.5 + [(29.8 - 8.5) / (250 - 100)] × (180 - 100) = 8.5 + (21.3 / 150) × 80 = 8.5 + 11.36 = 19.86 ms
  • Para T = 20 ms: 20 = 8.5 + 0.142 × (n - 100) ⇒ 11.5 / 0.142 = n - 100 ⇒ n ≈ 80.99 + 100 = 180.99 ≈ 181

Ejercicio 4

Para f(x) = sin(x), utiliza los puntos x0 = π/6 y x1 = π/3 para aproximar sin(π/4).

Solución:

  • x0 = π/6 ⇒ y0 = sin(π/6) = 0.5
  • x1 = π/3 ⇒ y1 = sin(π/3) = √3 / 2 ≈ 0.866025
  • Aproximación: f(π/4) ≈ 0.5 + [(0.866025 - 0.5) / (π/3 - π/6)] × (π/4 - π/6) = 0.5 + [0.366025 / (π/6)] × (π/12) = 0.5 + 0.366025 × 0.5 ≈ 0.683013

Interpolación Polinomial de Lagrange

La interpolación polinomial es un método que permite construir un polinomio que pasa exactamente por un conjunto de puntos conocidos sin necesidad de calcular derivadas.

Construcción de un polinomio de grado máximo n a partir de n + 1 puntos.

Por ejemplo:

  • Con 2 puntos se construye un polinomio de grado máximo 1.
  • Con 3 puntos se construye uno de grado máximo 2.
  • Con 4 puntos se construye uno de grado máximo 3.

Fórmula:

Pn(x) = Σ yi × Li(x), donde la suma va desde i = 0 hasta n

Donde:

Li(x) = Π [(x - xj) / (xi - xj)], donde el producto va desde j = 0 hasta n, con j ≠ i

Ejemplo 2: Polinomio cuadrático

Tenemos los siguientes datos:

x f(x)
1 2
2 3
4 11

Aproximar f(3).

Identificación de datos:

  • (x0, y0) = (1, 2)
  • (x1, y1) = (2, 3)
  • (x2, y2) = (4, 11)

Construimos los términos Li(x):

  • L0(x) = (x - 2)(x - 4) / [(1 - 2)(1 - 4)] = (x - 2)(x - 4) / 3
  • L1(x) = (x - 1)(x - 4) / [(2 - 1)(2 - 4)] = -(x - 1)(x - 4) / 2
  • L2(x) = (x - 1)(x - 2) / [(4 - 1)(4 - 2)] = (x - 1)(x - 2) / 6

Construimos el polinomio:

P2(x) = 2L0(x) + 3L1(x) + 11L2(x)

Sustituir y simplificar: P2(x) = x2 - 2x + 3

Evaluamos: P2(3) = (3)2 - 2(3) + 3 = 6

Ejercicios de Interpolación Polinomial

Ejercicio 1: Segundo grado f(4)

x f(x)
1 4
3 10
5 24

Solución:

  • L0(4) = (4 - 3)(4 - 5) / [(1 - 3)(1 - 5)] = (1)(-1) / [(-2)(-4)] = -1/8
  • L1(4) = (4 - 1)(4 - 5) / [(3 - 1)(3 - 5)] = (3)(-1) / [(2)(-2)] = 3/4
  • L2(4) = (4 - 1)(4 - 3) / [(5 - 1)(5 - 3)] = (3)(1) / [(4)(2)] = 3/8
  • P2(4) = 4(-1/8) + 10(3/4) + 24(3/8) = -0.5 + 7.5 + 9 = 16

Ejercicio 2: Interpolación con puntos no equidistantes - Segundo grado f(3.5)

x f(x)
0 2
2 10
5 37

Solución:

  • L0(3.5) = (3.5 - 2)(3.5 - 5) / [(0 - 2)(0 - 5)] = (1.5)(-1.5) / [(-2)(-5)] = -2.25 / 10 = -0.225
  • L1(3.5) = (3.5 - 0)(3.5 - 5) / [(2 - 0)(2 - 5)] = (3.5)(-1.5) / [(2)(-3)] = -5.25 / -6 = 0.875
  • L2(3.5) = (3.5 - 0)(3.5 - 2) / [(5 - 0)(5 - 2)] = (3.5)(1.5) / [(5)(3)] = 5.25 / 15 = 0.35
  • P2(3.5) = 2(-0.225) + 10(0.875) + 37(0.35) = -0.45 + 8.75 + 12.95 = 21.25

Ejercicio 3: Tercer grado f(2.5)

x f(x)
0 1
1 3
2 13
4 91

Solución:

  • L0(2.5) = (2.5 - 1)(2.5 - 2)(2.5 - 4) / [(0 - 1)(0 - 2)(0 - 4)] = (1.5)(0.5)(-1.5) / [(-1)(-2)(-4)] = -1.125 / -8 = 0.140625
  • L1(2.5) = (2.5 - 0)(2.5 - 2)(2.5 - 4) / [(1 - 0)(1 - 2)(1 - 4)] = (2.5)(0.5)(-1.5) / [(1)(-1)(-3)] = -1.875 / 3 = -0.625
  • L2(2.5) = (2.5 - 0)(2.5 - 1)(2.5 - 4) / [(2 - 0)(2 - 1)(2 - 4)] = (2.5)(1.5)(-1.5) / [(2)(1)(-2)] = -5.625 / -4 = 1.40625
  • L3(2.5) = (2.5 - 0)(2.5 - 1)(2.5 - 2) / [(4 - 0)(4 - 1)(4 - 2)] = (2.5)(1.5)(0.5) / [(4)(3)(2)] = 1.875 / 24 = 0.078125
  • P3(2.5) = 1(0.140625) + 3(-0.625) + 13(1.40625) + 91(0.078125) = 0.140625 - 1.875 + 18.28125 + 7.109375 = 23.65625
