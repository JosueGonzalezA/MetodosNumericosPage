Escribe las funciones usando x, ^ para potencias y punto para decimales. Puedes usar sen, cos, tan, exp, ln, log, log10, raiz, absoluto, pi y e. También se aceptan sin, sqrt y abs.

Bisección

Si dejas Xi y Xf vacíos, se buscará un intervalo automáticamente. El error aproximado es Ea(x) = |(Xm actual - Xm anterior) / Xm actual| × 100%.

Punto fijo

Escribe f(x) y elige la forma despejada g(x) para resolver x = g(x). Se detiene cuando Ea = |(g(X) - X) / g(X)| × 100% es menor que el porcentaje indicado.

Newton-Raphson

La sucesión se calcula con xₙ₊₁ = xₙ - f(xₙ) / f'(xₙ). Se detiene cuando el cambio relativo entre dos valores consecutivos es menor que el porcentaje indicado.
