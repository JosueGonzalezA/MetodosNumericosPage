Calculadoras de métodos numéricos

Escribe las funciones usando x, ^ para potencias y punto para decimales. Puedes usar sen, cos, tan, exp, ln, log, log10, raiz, absoluto, pi y e. También se aceptan sin, sqrt y abs. Para el ejemplo de la foto sirven e^3x-4 y e^(3*x)-4.

Bisección

Elige Xi y Xf como extremos de un intervalo donde la función tenga signos opuestos. Cada Xm es el punto medio. El error aproximado es Ea(x) = |(Xm actual - Xm anterior) / Xm actual| × 100%; no se calcula en la primera fila.

Punto fijo

Escribe la función original f(x) y una forma despejada g₁(x) para resolver x = g₁(x). La tabla evalúa ambas funciones en cada X. Se detiene cuando Ea = |(g₁(X) - X) / g₁(X)| × 100% es menor que el porcentaje indicado.

Newton-Raphson

La sucesión se calcula con xₙ₊₁ = xₙ - f(xₙ) / f'(xₙ). Se detiene cuando el cambio relativo entre dos valores consecutivos es menor que el porcentaje indicado.

Si dejas la derivada vacía, se aproximará numéricamente.
